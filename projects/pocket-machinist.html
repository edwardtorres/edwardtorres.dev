Technical details

The repository carries the same product idea across a SwiftUI client targeting iOS 17 and a React/TypeScript PWA. The web client uses Workbox to cache its application shell and bundled data after the first successful load. Preferences, favorites, recents, and checklist state stay on the device.

Verification & limitations

Web lint and production build checks pass locally. Native validation and a native screenshot remain pending because they require macOS and Xcode.

Reference values are starting points, not substitutes for machine manuals or qualified judgment. Several reference-data families still need authoritative citations, and native/web feature coverage may differ.
