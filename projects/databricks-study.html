Technical details

The app runs entirely in the browser. SQL.js provides a SQLite engine with selected Databricks-style SQL adaptations. Chapter content, labs, and SQL practice are split into separate downloads. Hash routing and relative asset paths let the app run under this site's /databricks/ path.

The release review passed 153 unit tests, 77 development/production browser checks, and the production build. Content targets the October 30, 2025 exam guide, with verification flags for two documentation ambiguities. The home page links to the official exam page and guide.

Progress & limitations

Progress stays in each browser and does not automatically sync across devices. Export a backup before clearing site storage or moving devices. The app validates imported saves and warns when browser storage is unavailable.

The SQL sandbox and labs are learning simulations, not a connected Databricks workspace. This is independent practice material. The app's 80% mock-exam target is a study target, not an official passing score. Recheck official sources before taking the exam. Full offline support is not implemented.
