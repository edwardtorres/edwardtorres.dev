Technical details

Game rules and storage normalization are tested independently from the interface. Question banks and notes load on demand, while a service worker caches the app for offline study. Hash-based routing and relative asset URLs allow the build to run under this site's /az900/ path.

The release audit passes type checking, lint, 176 unit tests, the production build, and automated content checks. Content follows the July 20, 2026 skills outline, with Microsoft Learn links and verification flags for facts that may change.

Progress & limitations

Progress stays in each browser and does not automatically sync across devices. Use Profile's export/import controls to transfer a save. Clearing site storage can remove progress, so keep an export as a backup.

The mock exam score is an estimate, and this is an independent practice tool. Microsoft exam content and product details can change; recheck flagged facts against the linked sources. Offline use requires an initial online visit.
