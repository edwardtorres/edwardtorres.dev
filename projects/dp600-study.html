Technical details

Game state, scoring, review intervals, and readiness are derived from a versioned browser save. Typed content loads in separate chunks, and a service worker caches the app for offline study after the first visit. The app runs under this site's /apps/fabric-mill/ path.

Automated checks cover game rules, save migrations, puzzle evaluators, content coverage, and component behavior. Browser tests exercise desktop and phone flows, accessibility, production security headers, and offline use.

Progress & study notes

Progress stays in each browser. Use Settings to export a backup or import a save on another device. Hands-on labs require a Fabric trial, and some steps require Windows tools; the lab instructions identify those requirements.

Fabric Mill is an independent study aid and is not affiliated with or endorsed by Microsoft. Its questions are original practice material. Use the linked Microsoft Learn sources and official exam guide to check current requirements; mock scores do not guarantee an exam result.
