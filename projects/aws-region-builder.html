The problem

Cloud architecture study involves more than recalling service names. Learners need to connect security, resilience, performance, and cost decisions, recognize prerequisites, and return to weak topics without losing their place in a large exam outline.

Region Builder gives that outline a navigable shape. Buildings make individual skills visible; roads express dependencies; inspections connect reading to retrieval practice. A commissioned building marks progress through the game, while readiness is calculated separately from recorded answers.

Learning design

The study loop moves from source-backed notes to start-up checks, five-question inspections, and commissioning. Qualified portfolio buildings also offer placement checks. Multiple-response answers receive credit only when the selected set exactly matches the key.

Daily review uses spaced intervals and a local-day answer cap, with weak-topic questions filling spare capacity. Maintenance sets revisit commissioned buildings after poor review performance. Mock exams use a separate reserve and a 19/17/16/13 domain distribution to approximate the guide’s weights.

Content & verification

Notes and questions cite AWS documentation. Content checks map the bank to the exam’s four domains, 14 task statements, and 189 outline bullets. The repository records blind-answer reviews, source reviews, disputed claims, and items awaiting verification.

Puzzles compute outcomes from explicit rules instead of grading free-form text. Labs connect the study material to an actual AWS account and include account requirements, cleanup steps, and cost guardrails. Dated source snapshots and freshness checks help identify content that needs another review.

Technical architecture

The application runs entirely in the browser. React renders the map and study screens; TypeScript defines the content and game state. Feature modules and district content load in separate chunks, keeping the full question bank out of the initial JavaScript entry.

A versioned local save supports migrations and export/import. Workbox precaches the production app for offline study after installation. Its manifest, worker, icons, and assets are scoped to /apps/region-builder/, allowing it to share this Cloudflare Pages site with the other study apps.

Quality & deployment

Automated checks cover game rules, save migrations, question selection, puzzle evaluators, and component behavior. Desktop and phone browser tests exercise study flows, accessibility, production security headers, and offline use.

The release review corrected maintenance-question ordering and inconsistent random sorting, added subpath-aware asset and offline configuration, and strengthened the bundle check for entry files beneath a subpath. The portfolio serves the app with a scoped security policy and cache rules for fresh entry files and immutable hashed assets.

Tradeoffs & next steps

Browser-local progress avoids accounts and a backend, but it does not sync automatically between devices. Export a backup before clearing browser data. Full offline precaching downloads the study content up front; the initial code is split, but installation still needs a successful first visit.

The current result is a functioning study tool, with no claim of measured improvement in exam performance. Useful next steps include learner usability sessions and ongoing source review. Mock percentages cannot predict AWS scaled scores, and practical labs may incur AWS charges.
